# MongoDB Export Tool

这是一个使用 TypeScript 开发的 MongoDB 数据导出工具。

## 安装

```bash
npm install
```

## 开发

```bash
npm run dev
```

## 构建

```bash
npm run build
```

## 运行

```bash
npm start
```

## 项目结构

- `src/` - 源代码目录
- `dist/` - 编译后的 JavaScript 文件
- `package.json` - 项目配置和依赖
- `tsconfig.json` - TypeScript 配置
